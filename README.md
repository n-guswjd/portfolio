## 🚀 프로젝트 소개
진행한 프로젝트를 카드로 한눈에 보고, 상세 내용은 모달로 확인할 수 있게 만든 포트폴리오 사이트입니다. 동물병원 웹 플랫폼(PetCare)과 소품샵 관리 플랫폼(DearObjet)을 소개합니다.

- **사이트**: https://n-guswjd.github.io/portfolio/

---

## ✨ 주요 기능
- [x] 프로젝트 카드 목록 (프로젝트 유형, 소개, 주요 기술 스택)
- [x] "자세히 보기" 모달 (탭 구성, 화면 미리보기 이미지)
- [x] Contact 모달 (이메일 연락, GitHub 링크)

- **Tooling**: `Storybook v10`, `Vitest`, `Playwright`, `ESLint v10`
- **Deployment**: `GitHub Pages`

## 🏁 시작하기 (Getting Started)

### 사전 요구사항 (Prerequisites)
- Node.js v20.19 이상
- npm

### 설치 및 실행 (Installation)
1. 저장소 복제
   ```bash
   git clone https://github.com/n-guswjd/portfolio.git
   cd portfolio
   ```
2. 패키지 설치 및 실행
   ```bash
   npm install
   npm run dev
   ```
   브라우저에서 `http://localhost:5173`으로 접속합니다.

## 💡 사용법 (Usage)
Projects 탭에서 프로젝트 카드를 확인하고 "자세히 보기"로 상세 내용을 볼 수 있습니다. Contact 탭에서는 이메일과 GitHub로 연락할 수 있습니다.

- 사이트: https://n-guswjd.github.io/portfolio/
- UI 컴포넌트는 `npm run storybook`(포트 6006)으로 확인할 수 있습니다.
